Coordinator

Recibe workers por WebSocket y expone su estado por HTTP.

Servidores

Se actualiza cada 2 s con peticiones HTTP GET /status (polling).

WebSocket desconectado

El navegador abre su propia conexión con el coordinator. Los eventos server_joined y server_left llegan solos, sin pedirlos.

HTTP

Cada petición abre, responde y cierra. Útil para órdenes puntuales entre servidores.
